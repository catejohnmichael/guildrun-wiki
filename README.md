# Guildrun Wiki

A static reference wiki for **Guildrun** (Demo, Steam build `25323618`), covering heroes, abilities, classes, items, relics, rank upgrades, events, crossroads, stages, enemies, shop odds, formulas, and drop pools.

Everything here is generated directly from the game build's balancing data and localization tables, with mechanics that live in code recovered from the compiled binary — not community guesswork.

## Viewing it

Open **`index.html`** in a browser, or browse the hosted version via GitHub Pages (see the repo's Pages settings for the link).

- **Events** are split into designed *encounters* and the atomic *reward building blocks* they draw from. Cards pop out on click; hover any item or relic for its stats.
- Item/relic/ability/hero art is included under `icons/`.

## Notes

Generated content — the pages are built by a tooling pipeline, so edits should be made to the generator rather than the HTML directly.
