Reward building blocks

← Back to Encounters

These are not standalone encounters. Each is a single parameterised reward grant — a common/rare item of a given stat, a pile of shards, a stat bonus, a hero of a given rank — that the designed events and crossroads reward pools draw from. Grouped here so the main Events page stays to real encounters.
