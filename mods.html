Mods

Small client-side quality-of-life mods for Guildrun, loaded with MelonLoader. They only change what your own screen shows. Nothing is sent to other players, and co-op partners don't need them; each player who wants a mod installs it. Built for Guildrun Demo 0.5.10 with MelonLoader 0.7.3.

Download all mods (.zip)

Install (one time, about 2 minutes)

  1. Close Guildrun.
  2. Download MelonLoader.Installer.exe from the official MelonLoader v0.7.3 release page.
  3. Run it, click SELECT and pick Guildrun.exe (Steam: right-click Guildrun Demo › Manage › Browse local files). Choose version v0.7.3 and click INSTALL.
  4. Start Guildrun once and let it reach the main menu, then quit. The first start is slow while MelonLoader sets itself up, and a console window opens next to the game.
  5. Put the mod .dll files in the Mods folder inside the Guildrun Demo folder.
  6. Play from Steam as usual. There's no separate launcher; the console lists each mod it loaded.

Mods

AlwaysOnGrid v1.0.0Play-tested

Keeps the placement grid visible while you position heroes, so you no longer have to lift a hero to see it.

Vanilla Guildrun only draws the hex grid while you are holding a hero. With several people positioning in co-op that means constant picking-up just to see the tiles. This mod keeps the resting grid visible during the Shop and Placement phases (your half and the enemy half). While you drag, the game's normal valid and invalid tile colours still take over, and the grid hides for the fight as usual.

EventPanelMover v1.1.0New in this release: top-right placement

Moves the Event Effect / Challenge banner out from under the fight timer, where it covers the top enemies' HP bars.

The banner (for example 'Event Effect: Rested') normally hangs centred under the timer, right on top of boss and top-row enemy HP bars. This mod pins it to the top-right, in the empty space under the battle-speed buttons. It still appears, disappears, collapses and expands exactly as before; only its position changes.

BattleRecorder v1.0.0Beta, not yet play-tested

Records every fight to a file: every hit, heal, status effect and death, with the hero, enemy, item, relic or ability behind it. Review them in the Fight viewer.

The game already keeps a complete combat log during each fight but throws it away afterwards. This mod saves it as one JSON file per fight: your lineup and items, the enemies, the result and length, every combat event with its timing, and the game's own per-hero and per-relic counters. Open the files in the Fight viewer on this wiki for per-hero damage split by source, which items and relics actually did the work, a damage-over-time chart and the full searchable log. It only reads; it never changes a fight.

SaveStates v1.0.0Beta, not yet play-tested

Save states for solo runs: every fight's start is checkpointed automatically, and you can reload any checkpoint to replay that fight with a different lineup.

Each time a fight's placement phase begins, the mod keeps a copy of the game's own save (a checkpoint). F5 makes a manual snapshot during Shop or Placement. F8 opens a list of this run's snapshots with Load buttons, and F9 loads the latest. Loading goes through the game's own routes (back to the menu, restore the save, Continue), so it behaves like quitting and continuing. Fight randomness comes from the run seed and your progress, so a reloaded fight plays out the same unless you change something, which makes it a fair A/B test. Snapshots live in Guildrun Demo\UserData\SaveStates. It's switched off in co-op, and by default in Endless runs because those go on the leaderboard. Profile progress (unlocks, mastery) is not rolled back.

StartingRerolls v1.0.0Beta, not yet play-tested

Every new run starts with at least 2 rerolls of the starting-hero pick.

Rerolling the starting heroes costs a Bonus Token, the token icons next to the difficulty in the bottom-left. Runs don't grant any, and how many you can hold depends on the token slots you've unlocked (up to 4). When a new run begins, this mod tops you up to at least 2 tokens, using the game's own token grant, before the hero picker opens. Continuing a saved run isn't affected. The tokens are profile currency, so any you don't spend carry over to the next run as usual. It changes your odds of a good start, so keep that in mind for runs that go on the Endless leaderboard.

Settings, updating and removing

  • Settings are in Guildrun Demo\UserData\MelonPreferences.cfg, which appears after the first launch with a mod. Edit it with the game closed, or restart the game afterwards.
  • Updating a mod: replace its .dll in Mods.
  • Steam launch options (right-click Guildrun Demo › Properties): --melonloader.hideconsole hides the console window; --no-mods starts the game without any mods.
  • After a game update a mod can stop working until it's rebuilt. If something looks wrong, start with --no-mods and check back here for a new version.
  • Uninstall: delete the .dll files from Mods. To remove MelonLoader too, run its installer again and click UNINSTALL.
  • Bug reports: Guildrun Demo\MelonLoader\Latest.log shows what each mod did.
