Rules that shape the map

  • Exactly one combat trial per run. Each eligible floor rolls it at 33%; if it hasn't happened by the last eligible floor it is forced there — floor 4: 33%, floor 7: 22%, floor 10: 45%. A trial is a Trial event (Single Combat / Endurance / Demolition / Rematch) with no death penalty.
  • Event rank-ups are capped by act: Act 1 events can only rank up a rank-C hero, Act 2 up to rank-B (so C→B, or B→A).
  • No repeats: a crossroads already used this run is skipped when a pool is rolled; random-event pools skip events you've already seen.
  • Shops: after every fight. Odds and pity are on Shop & Odds.
